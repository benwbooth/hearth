KDE colour schemes for `hearth-color-scheme`, copied from KDE's Breeze
(breeze 6.6.6, `share/color-schemes`). They are hearth's palette (shell/Theme.qml
uses the same colours). The helper writes them into kdeglobals with hearth's
accent and fonts on top. They live here because Breeze's own copies went with
Plasma: without them kdeglobals was never updated, and light mode never reached
KDE/Kirigami apps.
